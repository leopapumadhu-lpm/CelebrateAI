# CelebrateAI 🎉

A GenAI-powered celebration and event planning assistant.

## Features
- Wedding, birthday and community event planning
- Optional Google Gemini AI integration
- Personalized event concepts and ideas
- Budget allocation and visualization
- Event timeline
- Editable vendor checklist
- CSV and PDF downloads

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Gemini API
Add a Gemini API key in the application sidebar to enable AI-generated plans.
Without a key, the built-in planning engine works as a fallback.

## Deployment
Deploy this public GitHub repository using Streamlit Community Cloud.
